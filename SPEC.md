GravitySwitcher is a game where the player can reverse gravity at any moment and walk on either the floor or the ceiling.
Instead of relying on basic jumping, the player has to use gravity changes to get past  obstacles and collect keys to reach the end.

The main challenge is from thinking about movement differently as players have to time gravity switches, and use both the floor and ceiling.


Intended Features:
A character that moves left and right
Gravity switching using the Space key
Collision detection with floors, ceilings, walls, and platforms
Collectible keys
A restart option when the player touches an obstacle or presses R
Spikes that reset the current level.

Acceptance Criteria and Priority 1:
1. Pressing arrow keys moves the player horizontally
2. Pressing Space changes the direction of gravity. 
3. The player cannot pass through solid floors, ceilings, walls
4. Touching a key removes it from the level and changes the exit from locked to unlocked.
5. Touching the exit before collecting the key does not complete the level. 
6. At least one level can be completed from start to finish using movement, gravity switching, key collection, and the exit.

Priority 2:
7. Touching spikes resets the player's position 
8. The game includes a few levels that progress automatically
9. Pressing R resets the current level
10. The screen displays the current level number and basic controls.
11. Completing the final level displays a message indicating that the player has won.

Priority 3 
12. Switching gravity has a visible effect
13. Sounds play when switching gravity or completing a level.


If time is short, visual effects and sound should be removed first.
The most important part is that gravity switching feels fast and works correctly


The initial focus:
1. Creating the game screen and the player.
2. left and right movement.
3. gravity switching.
4. Adding basic floor and ceiling collision.
5. Creating the basic structure for levels.

Then:
1. Improving collision for walls and platforms.
2. keys and locked exits.
3. Adding spikes
4. Adding the victory screen.
